# Scene Panel для SillyTavern

Панель сцены для ролевых игр: день, дата, место, время, погода, кто рядом и какие нити остались открытыми. Состояние живёт **внутри чата**, поэтому у каждой истории свой календарь.

Главное отличие от заметок вручную: ИИ может **сам** обновлять состояние тегом в конце сообщения. Тег вырезается из текста, в чате его не видно.

## Что даёт

- **календарь** — счётчик дня плюс свободная строка даты («12-е, месяц Сиреневой Луны»);
- **обстановка** — место, время суток, погода;
- **кто рядом** — список персонажей в сцене;
- **открытые нити** — что висит и ждёт развития;
- **тон сцены** — эмоциональная рамка одним словом или фразой;
- **инжект в промпт** — состояние автоматически попадает в контекст, и модель не теряет «где мы» после паузы в неделю.

## Установка

1. Скопируйте папку в `SillyTavern/public/scripts/extensions/third-party/scene-panel`.
2. Перезагрузите страницу таверны.
3. Откройте «Расширения» — там появится блок **Scene Panel**.

Установка по URL (если ваша сборка умеет):

```
https://github.com/<ваш-ник>/scene-panel
```

## Формат тега

В конце сообщения ИИ пишет служебную строку. Ключи можно по-русски или по-английски, разделитель — `;`:

```
[[scene: день=+1; место=Дворец Ночи, покои Ризанда; время=утро; рядом=Ризанд; висит=разговор с Фейрой, Никс ждёт ответа; тон=хрупкое перемирие]]
```

Поддерживаемые ключи:

| Русский | English | Значение |
| --- | --- | --- |
| `день` | `day` | число, либо `+1` / `следующий` |
| `дата` | `date` | свободная строка |
| `место` | `place`, `где` | свободная строка |
| `время` | `time` | `утро`, `ночь`, … |
| `погода` | `weather` | свободная строка |
| `рядом` | `present`, `кто` | через запятую |
| `висит` | `open`, `нити` | через `;` или `\|` |
| `тон` | `mood` | свободная строка |

Тег обрабатывается на `MESSAGE_RECEIVED`: состояние обновляется, тег стирается из отображаемого текста, метаданные чата сохраняются.

## Настройки

- **вставлять сцену в промпт** — включён по умолчанию;
- **роль инжекта** — `system` / `user` / `assistant`;
- **плавающая панель в чате** — компактная карточка в правом нижнем углу (скрывается на узких экранах).

## Важно

- Панель не требует серверных модулей и ничего не пишет в файлы — только `chat_metadata`.
- Если модель не пишет тег, панель работает как обычная ручная панель: всё правится полями в «Расширениях».
- Кнопка «сбросить» очищает состояние текущего чата.
