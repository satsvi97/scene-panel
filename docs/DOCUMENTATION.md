# ✦ SCENE PANEL ✦ — Полная документация

**Версия:** 0.10.2 · **Платформа:** SillyTavern (third-party extension) · **Лицензия:** MIT © 2026 Selena's Tavern (satsvi97)

> Документ описывает внутреннее устройство расширения, модель данных, форматы, интеграции и ограничения.
> Пользовательская инструкция — в [README](../README.md). План тестирования — в [TESTPLAN](TESTPLAN.md).

## 1. Назначение

Scene Panel хранит **состояние сцены** ролевой игры и держит его в актуальном виде двумя способами:

1. **вручную** — поля панели;
2. **автоматически** — служебный тег `[[scene: …]]` в конце ответа модели.

Состояние привязано к **чату** (`chat_metadata`), поэтому у каждой истории свой календарь, состав сцены и статистика. Состояние автоматически инжектится в промпт, чтобы модель не теряла контекст «где мы и когда».

| `panel.html` | **Легаси.** Не используется с версии 0.6.4: разметка панели встроена в `index.js` (`PANEL_HTML`), чтобы обойти кэш шаблонов. Файл оставлен для совместимости. |

| `.github/ISSUE_TEMPLATE/*` | Формы багов и идей. |

### 2.2 Точка входа и инициализация

`index.js` — ES-модуль. Порядок инициализации (`jQuery(async () => …)`):

1. `renderExtensionTemplateAsync(EXT_NAME, 'settings')` → вставка drawer в `#extensions_settings2`;
2. вставка `PANEL_HTML` в модальное окно (`mountModal`);
3. `mountTopButton()` — кнопка `☾` в `#top-settings-holder` (или fixed-кнопка, если контейнера нет);
4. вставка `floating.html` в `body` + подпись версии;
5. подхват `saveSettingsDebounced` из `script.js` (если доступен);
6. `getSettings()`, `getState()`, `bindEvents()`, `enableDrag()`, `initPanelSlider()`, `applyLanguage()`, `refresh()`, `syncPrompt()`, `applyWeatherEffect()`;
7. подписки на события (см. 2.4).

Инициализация обёрнута в `try/catch`: ошибка инициализации пишется в консоль и не должна валить таверну.

## 3. Модель данных

### 3.1 Состояние сцены — `chat_metadata.scene_panel`

```js
{
  day: 1,              // абсолютный номер дня, >= 1
  daysInMonth: 30,     // 5..60
  monthLabel: '',      // произвольное название месяца
  date: '',            // «12-е, месяц Сиреневой Луны»
  place: '',
  timeOfDay: '',
  weather: '',
  present: [],         // массив строк
  open: [],            // массив строк (нити)
  mood: '',
  sessionDay: 1,       // счётчик сессии: день
  sessionHour: 0,      // 0..23
  sessionMinute: 0,    // 0..59
  custom: {},          // произвольные поля { ключ: значение }
}
```

`getState()` нормализует значения при каждом чтении: числа приводятся к целым и клампятся, строки — к `''`, массивы чистятся от пустых элементов, `custom` — всегда объект.

### 3.2 История снимков — `chat_metadata.scene_panel_history`

Массив до **20** элементов:

```js
{ ts: 1699999999999, key: "<JSON состояния>", state: { …копия состояния… } }
```

- снимок добавляется только если его `key` отличается от последнего;
- при переполнении самый старый вытесняется (`shift`);
- снимок делается **перед «сбросить»**, поэтому сброс откатываемый.

### 3.3 Статистика — `chat_metadata.scene_panel_stats`

```js
{
  updates: 0, firstTs: 0, lastTs: 0, maxDay: 1,
  places: {}, times: {}, weather: {}, chars: {}   // { значение: количество }
}
```

- `updates` увеличивается при каждом «осмысленном» обновлении сцены (тег ИИ — сразу; ручной ввод — с дебаунсом 900 мс);
- `maxDay` — максимум достигнутого дня;
- `chars` пополняется из `present`, `places`/`times`/`weather` — из соответствующих полей.

Статистика хранится **отдельно** от сцены и не стирается кнопкой «сбросить». Очищается своей кнопкой.

### 3.4 Настройки — `extension_settings.scene_panel`

| Ключ | Тип | По умолчанию | Значение |
|---|---|---|---|
| `enabled` | boolean | `true` | Главный выключатель. |
| `inject` | boolean | `true` | Вставлять сцену в промпт. |
| `role` | string | `'system'` | `system` / `user` / `assistant`. |
| `floating` | boolean | `true` | Плавающая карточка. |
| `floatPos` | `{x,y}` \| null | `null` | Позиция карточки в px. |
| `weatherIntegration` | boolean | `true` | Управление Weather Background. |
| `theme` | string | `'auto'` | `auto` / `dark` / `light`. |
| `lang` | string | `'ru'` | `ru` / `en` / `uk` / `sv`. |

## 4. Формат тега

### 4.1 Грамматика

```
[[scene: <параметр>; <параметр>; … ]]
```

- ключ и значение разделяются `=` (допускается `:`);
- параметры разделяются `;`;
- тег ищется регуляркой `/\[\[\s*scene\s*:\s*([\s\S]*?)\]\]/i` — **первый** тег в сообщении;
- имена ключей сравниваются в нижнем регистре.

### 4.2 Ключи и алиасы

| Поле | ru | en | uk | sv |
|---|---|---|---|---|
| день | `день` | `day` | `день` | `dag` |
| дата | `дата` | `date` | `дата` | `datum` |
| место | `место`, `где` | `place` | `місце`, `де` | `plats` |
| время | `время` | `time`, `timeofday` | `час` | `tid` |
| погода | `погода` | `weather` | `погода` | `väder`, `vader` |
| рядом | `рядом`, `кто` | `present` | `поруч`, `хто` | `närvarande`, `narvarande` |
| висит | `висит`, `нити` | `open`, `threads` | `висить`, `нитки` | `trådar`, `tradar` |
| тон | `тон` | `mood` | `тон` | `ton` |

### 4.3 Значения

- **день:** целое > 0, либо `+1` / `следующий` / `наступний` / `nästa` / `nasta`.
- **рядом:** разбивается по запятой, пробелы обрезаются.
- **висит:** разбивается по `;` или `|`.
- **остальные:** строка как есть.
- **неизвестные ключи** попадают в `custom` (кроме `время_сессии` / `time_session`).

### 4.4 Обработка сообщения

1. Найти тег; если нет — ничего не делать.
2. Распарсить в патч.
3. `custom`-поля смёржить с существующими; остальные — `Object.assign` в состояние.
4. Вырезать тег из `message.mes`, обрезать хвостовые пробелы.
5. `updateMessageBlock(id, message, { rerenderMessage: true })`.
6. `commit()` → сохранение метаданных + обновление плавающей карточки.
7. `recordSnapshot()`, `trackStats()`, `syncPrompt()`, `refresh()`, `applyWeatherEffect()`.

### 4.5 Ограничения формата

- В значениях нельзя использовать `;` (разделитель параметров) и `|` в поле «висит».
- В «рядом» нельзя использовать запятую внутри имени.
- Учитывается только **первый** тег в сообщении.
- Тег не парсится в сообщениях пользователя (только `MESSAGE_RECEIVED`).

## 5. UI

### 5.1 Модальное окно

- `#scene_panel_modal` → `.scene-panel-modal-card` → шапка + тело;
- шапка: заголовок `✦ SCENE PANEL ✦`, кнопка `📊` (переключение страниц), чип `день N`, переключатель языков `RU EN UK SV`, `×`;
- тело: слайдер из двух страниц.

### 5.2 Слайдер страниц

- `.scene-panel-track` шириной 200 %, слайды по 50 %;
- класс `is-stats` сдвигает на `-50 %`;
- переключение: свайп (±40 px), точки внизу, кнопка `📊`;
- вертикальные жесты не перехватываются: после 8 px определяется ось; если ось `y` — свайп игнорируется;
- при закрытии панель возвращается на страницу сцены.

### 5.3 Страница «Сцена»

Порядок блоков: подсказка тега → календарь → название/длина месяца → дата → место → время (с чипами) → погода → рядом (с чипами) → нити → тон → счётчик сессии → доп. поля → диагностика + сброс → настройки → подпись/версия.

- **календарь:** сетка 7 колонок, сегодняшний день выделен, будущие приглушены; стрелки переключают месяц; клик по дню выставляет абсолютный день.
- **чипы времени:** значения из словаря активного языка; повторный клик снимает выбор.
- **чипы персонажей:** имена из `getContext().characters` + `name1`/`name2`, отфильтрованные по упоминанию в последних 10 сообщениях и отсутствию в `present`, максимум 8.
- **счётчик сессии:** `день N, ЧЧ:ММ`; кнопки ±час (с переходом через сутки, не ниже `день 1, 00:00`) и ±день.
- **диагностика:** см. §8.

### 5.4 Страница «Статистика»

Строки: обновления + максимальный день; топ-3 персонажей, мест, времени, погоды. Кнопки «обновить», «очистить».

### 5.5 Плавающая карточка

- `#scene_panel_float`, перетаскивание за шапку (Pointer Events + `setPointerCapture`);
- позиция клампится в вьюпорт и сохраняется в `floatPos`;
- кнопки: `−`/`+` день, свернуть, скрыть (выключает `floating`);
- контент: день, место, время · погода, рядом, тон, нити, версия.

### 5.6 Темы

- атрибут `data-sp-theme="dark|light"` на `#scene_panel_modal` и `#scene_panel_float`;
- `auto` определяет тему по яркости `background-color` у `body` (порог 140); при фоне-картинке может ошибиться и уйти в `dark`;
- светлая тема — сиреневые градиенты (`#f4eefc → #e7ddf7`), затемнённые цифры, отдельная палитра частиц.

### 5.7 Локализация

- словарь `I18N` на 4 языка; ключи — плоские строки; для подсказок допускается HTML (`<code>`, `<br>`);
- разметка помечена **уникальными** атрибутами `data-sp-i18n`, `data-sp-ph`, `data-sp-title`;
- `applyLanguage()` обходит **только** контейнеры расширения (`#scene_panel_modal`, `#scene_panel_settings_compact`, `#scene_panel_float`) и только ключи, существующие в словаре;
- обёрнута в `try/catch` — сбой локализации не ломает таверну;
- динамические строки (статистика, диагностика, чипы, плавающая карточка) используют `t()` / `tf()`.

> ⚠️ Историческая заметка: в 0.10.0 глобальный поиск `[data-i18n]` конфликтовал с собственной i18n SillyTavern (ключи `[title]…`). Исправлено в 0.10.1–0.10.2; использовать глобальные селекторы для правки DOM нельзя.

## 6. Промпт-инжект

`sceneText(state)` собирает строку:

```
Сцена: день N (месяц M, D-е). месяц: … . дата: … . место: … . обстановка: время, погода .
рядом: … . не закрыто: … . тон: … . доп: k=v; … . время сессии: день N, ЧЧ:ММ .
Это текущее состояние сцены. Если в твоём ответе меняются место, время, состав сцены,
закрываются или появляются нити — добавь в самом конце ответа ровно одну строку
[[scene: место=…; время=…; рядом=…; висит=…; тон=…; погода=…]] и не упоминай её в тексте.
```

Инжект: `setExtensionPrompt(PROMPT_KEY, text, extension_prompt_types.IN_PROMPT, 0, false, role)`.
При выключенном `inject` или `enabled=false` — `setExtensionPrompt(..., NONE, ...)`, то есть строка удаляется.

## 7. Интеграция с Weather Background

- при включённой галочке и валидной погоде выполняется ленивый `import('../sillytavern-weather-background/src/background-renderer.js')`;
- вызывается `setWeatherEffect(state, { mobileMode })`, где `state ∈ {rain, thunderstorm, snow, blizzard, cloudy, sunny, hail, clear}`;
- учитываются настройки WB: при `extension_settings.weather_background.enabled === false` эффект не применяется; `mobileMode` пробрасывается;
- при отсутствии расширения импорт падает → предупреждение в консоль, промис сбрасывается, повторная попытка при следующем вызове;
- сброс сцены вызывает `applyWeatherEffect(true)` → `clear`;
- при смене чата эффект применяется повторно через 250 мс (перекрывает очистку со стороны WB).

Маппинг погоды:

| Значение сцены | Состояние WB |
|---|---|
| дождь / ливень / rain / shower | `rain` |
| гроза / thunderstorm / storm | `thunderstorm` |
| снег / snow | `snow` |
| метель / blizzard | `blizzard` |
| облачно / пасмурно / cloudy / overcast | `cloudy` |
| солнечно / sunny | `sunny` |
| град / hail | `hail` |
| ясно / clear | `clear` |
| нет / none | `none` |

## 8. Диагностика и история

`runDiagnostics()`:

1. `collectTagsFromRecent(12)` — обход последних 12 сообщений **от новых к старым**, для каждого берётся первый тег;
2. если теги найдены — применяется патч **самого свежего**;
3. иначе берётся **последний снимок** из истории;
4. иначе — сообщение «нечего восстанавливать»;
5. результат выводится под кнопкой (`Тегов: N. Снимков: M. …`).

Восстановление всегда вызывает `commit → syncPrompt → refresh → applyWeatherEffect`.

## 9. Производительность и безопасность

- нет сетевых запросов и серверных модулей; всё в браузере;
- запись — только в `chat_metadata` и `extension_settings`;
- дебаунс сохранения метаданных (`saveMetadataDebounced`) и статистики (900 мс);
- история ограничена 20 снимками, статистика — словарями счётчиков;
- DOM-правки строго в своих контейнерах; локализация не трогает чужие узлы;
- сообщение модели очищается от тега и перерисовывается точечно (`updateMessageBlock`).

### Известные ограничения

1. Версия дублируется в `manifest.json` и `PANEL_VERSION` — синхронизировать вручную.
2. `panel.html` больше не используется (легаси).
3. Позиция плавающей карточки — в пикселях, без привязки к DPI.
4. `auto`-тема ненадёжна при фоне-картинке.
5. Свайп-порог и горячая клавиша не настраиваются.
6. Сцена не экспортируется/не импортируется.
7. Тег читается только из ответов ассистента.
8. Автотестов нет.

## 11. Терминология

- **сцена** — набор полей состояния (`place`, `timeOfDay`, `present`, …);
- **тег** — служебная строка `[[scene: …]]` в ответе модели;
- **снимок** — сохранённая копия состояния для отката;
- **нити** — открытые сюжетные линии (`open`);
- **сессия** — счётчик «день/время», независимый от календарного дня;
- **инжект** — вставка текста сцены в промпт.
