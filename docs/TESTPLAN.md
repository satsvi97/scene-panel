# ✦ SCENE PANEL ✦ — План тестирования

**Версия объекта:** 0.10.2 · **Тип:** расширение SillyTavern (клиентское, ES-модуль) · **Документация:** [DOCUMENTATION](DOCUMENTATION.md)

---

## 1. Цель

Проверить, что расширение:

1. корректно хранит и восстанавливает состояние сцены в рамках чата;
2. безопасно сосуществует с SillyTavern и другими расширениями (не ломает чужой DOM);
3. корректно парсит тег `[[scene: …]]` на 4 языках и не портит текст сообщений;
4. корректно инжектит сцену в промпт и управляет фоном Weather Background;
5. устойчиво к некорректным данным, перезагрузкам, смене чатов и мобильным экранам.

## 2. Область

**Входит:** состояние сцены, парсинг тега, промпт-инжект, модальная панель, плавающая карточка, календарь, счётчик сессии, доп. поля, диагностика и история, статистика, локализация (RU/EN/UK/SV), темы, интеграция Weather Background, горячие клавиши, хранение данных, совместимость с другими расширениями.

**Не входит:** серверная часть SillyTavern, качество генерации модели, сторонние расширения (кроме точек интеграции), UI самого SillyTavern.

## 3. Окружение и матрица

### 3.1 Обязательное окружение

- SillyTavern (актуальный релиз; минимум — версия с `extension_prompt_roles` и `renderExtensionTemplateAsync`);
- расширение установлено в `public/scripts/extensions/third-party/scene-panel`;
- чистый чат с 2+ персонажами и 10+ сообщениями для проверки чипов;
- Weather Background установлен (для блока WB) и отдельно — сценарий без него.

## 4. Тестовые данные (фикстуры)

**F1. Базовый тег**

```
[[scene: день=+1; место=Дворец Ночи; время=утро; рядом=Ризанд, Фейра; висит=разговор с Фейрой; погода=дождь; тон=хрупкое перемирие]]
```

**F2. Английский тег** — `[[scene: day=3; place=Night Palace; time=night; present=Rhysand; open=wait for Nyx; weather=snow; mood=cold]]`

**F3. Украинский тег** — `[[scene: день=5; місце=Палац Ночі; час=вечір; поруч=Ризанд; висить=розмова; погода=гроза; тон=крихке перемир'я]]`

**F4. Шведский тег** — `[[scene: dag=+1; plats=Nattpalatset; tid=morgon; närvarande=Rhysand; trådar=samtal; väder=snö; ton=skör vapenvila]]`

**F5. Доп. поля** — `[[scene: сюжет=погоня; напряжение=высокое; day=+1]]`

**F6. Негативные** — пустой тег, тег без ключей, `[[scene:]]`, `[[scene: день=abc]]`, `[[scene: день=-5]]`, два тега в одном сообщении, тег в середине текста.

## 8. Отчёт о дефекте

Использовать форму [bug_report.yml](../.github/ISSUE_TEMPLATE/bug_report.yml). Обязательно:

1. версия (из угла панели);
2. способ установки;
3. шаги воспроизведения;
4. ожидаемо/фактически;
5. тема панели, наличие WB, язык панели;
6. скриншот + консоль (F12).

Приоритет дефекта:

| Severity | Критерий |
|---|---|
| S1 Blocker | Панель/таверна не работают, теряются данные |
| S2 Major | Ключевая функция не работает (тег, инжект, восстановление) |
| S3 Minor | Работает с обходным путём (локализация, тема) |
| S4 Cosmetic | Вёрстка, отступы, опечатки |

| Конфликт с чужой i18n/DOM | Средняя | Высокое | Уникальные `data-sp-*`, скоупленные селекторы, TC-I18N-07 |
| Кэш шаблонов после обновления | Высокая | Среднее | Встроенный `PANEL_HTML`, `Ctrl+F5` в инструкции |
| Расхождение версий manifest/PANEL_VERSION | Средняя | Низкое | Пункт чек-листа |
| Ошибки свайпа на iOS Safari | Средняя | Среднее | `touch-action: pan-y`, порог 40 px, TC-UI-01..03 |
| Некорректный `auto`-тема при фоне-картинке | Высокая | Низкое | Ручной выбор темы |
| Потеря сцены при откате чата | Низкая | Среднее | Снимки (до 20) + диагностика |
| Сторонние расширения меняют DOM панели | Низкая | Низкое | Свои id/классы, не полагаться на чужие селекторы |

## 10. Автоматизация (рекомендации)

- **Playwright**: смоук-путь (загрузка ST → открытие панели → ввод полей → перезагрузка → проверка сохранения); проверка отсутствия `TypeError` в консоли.
- **Юнит-уровень**: вынести `parseTag`, `mapWeatherToState`, `elapsedTimeString`, `monthTitle`, `snapshotKey` в чистые функции и покрыть табличными тестами (node:test).
- **Фикстуры**: сообщения F1–F6 в виде JSON для прогона парсера без ST.
- **Регрессия i18n**: отдельный тест, который проверяет, что после `applyLanguage()` ни один элемент вне контейнеров расширения не изменён (сравнение `outerHTML` до/после).
